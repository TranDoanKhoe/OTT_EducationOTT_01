Tổng quan dự án

Dự án hướng đến mô hình học tập trực tuyến có giao tiếp tức thời, phù hợp cho sinh viên, giảng viên và nhóm học tập cần trao đổi nhanh trong cùng một hệ thống.

CLO 1 - CLO 5
M

Mobile App

Ứng dụng React Native với Expo Router, dùng cho chat, danh bạ, thông báo, lớp học và tài nguyên.

W

Web App

Ứng dụng React + Vite hỗ trợ giao diện quản trị, chat, quản lý người dùng và thống kê.

B

Backend

Spring Boot cung cấp RESTful API, WebSocket/STOMP, xác thực JWT và kết nối MongoDB.

Tính năng chính

Các tính năng được nhóm phát triển theo hướng thực tế: đăng nhập, chat, bạn bè, nhóm, thông báo, tài nguyên, cuộc gọi và quản lý tài khoản.

01

Xác thực tài khoản

Đăng nhập, đăng ký, xác thực email, quên mật khẩu và lưu token cho phiên làm việc.

  • ✓JWT access token và refresh token.
  • ✓Ghi nhớ tài khoản đăng nhập.
  • ✓Đặt lại mật khẩu bằng mã email.
02

Chat real-time

Nhắn tin 1-1 và nhóm với WebSocket/STOMP, đồng bộ trạng thái nhanh giữa web và mobile.

  • ✓Gửi tin nhắn văn bản, file, ảnh.
  • ✓Ghim, thu hồi, xóa, chỉnh sửa tin nhắn.
  • ✓Tìm kiếm tin nhắn theo từ khóa.
03

Danh bạ và bạn bè

Tìm người dùng bằng số điện thoại, gửi lời mời, chấp nhận hoặc từ chối kết bạn.

  • ✓Danh sách bạn bè sắp xếp theo tên.
  • ✓Tìm bạn bè bằng danh bạ điện thoại.
  • ✓Xóa bạn bè hoặc chặn người dùng.
04

Nhóm học tập

Tạo nhóm, mời thành viên, ghi chú nhóm, bình chọn và quản lý lời mời vào nhóm.

  • ✓Tạo nhóm từ danh sách bạn bè.
  • ✓Quản lý lời mời nhóm.
  • ✓Ghi chú và poll hỗ trợ học nhóm.
05

Thông báo

Hiển thị lời mời kết bạn và nhóm, cho phép tìm kiếm, lọc nhanh và xử lý ngay trên mobile.

  • ✓Lọc thông báo theo loại.
  • ✓Tìm kiếm theo tên hoặc nhóm.
  • ✓Đồng ý hoặc từ chối lời mời.
06

Cuộc gọi WebRTC

Hỗ trợ cuộc gọi audio/video, xử lý quyền media và tín hiệu cuộc gọi qua WebSocket.

  • ✓Gọi 1-1 audio/video.
  • ✓Gọi nhóm trong group chat.
  • ✓Hướng dẫn cấp quyền thiết bị.

Kiến trúc hệ thống

Hệ thống tách thành client mobile, client web và backend tập trung. RESTful API xử lý dữ liệu, WebSocket/STOMP xử lý real-time, WebRTC xử lý luồng media.

Công nghệ sử dụng

Danh sách công nghệ bám sát yêu cầu CLO 1, đồng thời thể hiện cách dự án ứng dụng từng công nghệ.

Nhóm công nghệ Công nghệ Vai trò trong dự án
Mobile React Native, Expo, Expo Router Xây dựng ứng dụng mobile đa nền tảng, điều hướng theo file, quản lý màn hình chat và tài khoản.
Web React, Vite Xây dựng giao diện web, quản trị hệ thống, chat và thống kê người dùng.
Backend Spring Boot Cung cấp RESTful API cho xác thực, người dùng, bạn bè, nhóm, tài nguyên và tin nhắn.
Database MongoDB Lưu trữ user, message, group, resource, verification code và các cấu hình liên quan.
Bảo mật JWT, Refresh Token Xác thực request, quản lý phiên đăng nhập và bảo vệ API backend.
Real-time WebSocket, STOMP, SockJS Gửi nhận tin nhắn tức thời, typing status, tín hiệu cuộc gọi và cập nhật nhanh.
Media WebRTC Thiết lập audio/video call giữa người dùng, trao đổi offer/answer/ICE candidate.
HTTP Client Axios, Fetch API Gọi REST API, upload file, lấy lịch sử chat, cập nhật hồ sơ và đổi mật khẩu.

Khái niệm cần trình bày

Phần này có thể dùng trực tiếp khi thuyết trình CLO 1 về các khái niệm kỹ thuật trong dự án.

HTTP là gì?

HTTP là giao thức truyền tải dữ liệu giữa client và server. Trong dự án, HTTP được dùng khi mobile hoặc web gọi API để đăng nhập, lấy danh sách bạn bè, cập nhật hồ sơ, tải tài nguyên và gửi request không cần real-time.

RESTful API là gì?

RESTful API là cách thiết kế API theo tài nguyên, dùng HTTP method như GET, POST, PUT, DELETE. Ví dụ: POST /auth/login, GET /user/get-info-for-user, POST /message/upload-file.

WebSocket là gì?

WebSocket tạo kết nối hai chiều liên tục giữa client và server. Dự án dùng WebSocket/STOMP để gửi tin nhắn real-time, typing status và tín hiệu cuộc gọi.

WebRTC là gì?

WebRTC cho phép truyền audio/video trực tiếp giữa các client. Backend hỗ trợ phần signaling, còn luồng media chính đi qua peer connection giữa người dùng.

Kế hoạch kiểm thử

Checklist kiểm thử tập trung vào các luồng có rủi ro cao: auth, real-time chat, refresh token, notification và WebRTC.

STT Hạng mục Kịch bản kiểm thử Kết quả mong đợi
1 Đăng nhập Nhập tài khoản/mật khẩu đúng, sai, thiếu trường. Đăng nhập thành công hoặc hiển thị lỗi rõ ràng.
2 Ghi nhớ tài khoản Bật ghi nhớ, đăng nhập, đăng xuất rồi quay lại màn login. Tài khoản được tự động điền lại.
3 Quên mật khẩu Gửi email, nhập mã, đặt mật khẩu mới. Mật khẩu được cập nhật và có thể đăng nhập lại.
4 Chat real-time Mở mobile và web, gửi tin nhắn giữa hai tài khoản. Tin nhắn xuất hiện tức thời ở cả hai bên.
5 Tìm kiếm tin nhắn Nhập từ khóa trong màn chat. Danh sách kết quả đúng nội dung tìm kiếm.
6 Thông báo Gửi lời mời kết bạn/nhóm, lọc theo loại và tìm kiếm. Thông báo hiển thị đúng, lọc đúng, thao tác accept/reject được.
7 WebRTC Gọi audio/video giữa hai thiết bị thật. Thiết lập cuộc gọi, có âm thanh/hình ảnh ổn định.
8 Upload tài nguyên Chọn file/ảnh và gửi lên backend. File được lưu và hiển thị trong cuộc trò chuyện hoặc tài nguyên.

Tiến độ phát triển

Lộ trình có thể dùng để trình bày quá trình làm việc theo từng giai đoạn.

Phase 1

Phân tích yêu cầu

Xác định module chính: authentication, chat, call, notification, friend, group và resource.

Phase 2

Thiết kế kiến trúc

Tách web, mobile, backend; thống nhất API, websocket endpoint và mô hình dữ liệu MongoDB.

Phase 3

Xây dựng chức năng nền

Hoàn thiện login/register, quản lý token, user profile, friend list và nhóm học tập.

Phase 4

Tích hợp real-time

Tích hợp WebSocket/STOMP, chat history, typing status, pinned messages và upload file.

Phase 5

Kiểm thử và hoàn thiện

Kiểm thử mobile-web-backend, bổ sung reset password, filter notification và tài liệu báo cáo.
